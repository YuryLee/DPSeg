# 追加检查协议：稳定性、小目标与 Demo 可用性

## Material Passport

- Task: 用户要求继续完善已有 GraspNet 课程 Demo。
- Workflow: ARS experiment-agent run / validate。
- Date: 2026-10-02。
- Status: 在新增种子实验之前固定；已有 seed17 开发及测试结果已见。
- Evidence: 本地数据、真实训练与评测；不将重复视角视为独立样本。

## 1. 配对随机种子

保留原 seed17，追加 seed23、41；每个种子训练 E0（RGB）与 E2（RGB+深度加法融合）。
模型、数据划分、800 步预算、batch=2、初始化、增强、优化器和学习率与第二轮相同。
训练及评测关键源码通过 `reports/v3/replication_source_receipt.json` 与第二轮逐文件比对。
整体代码指纹包含 tools 目录，新增分析工具会改变该指纹，须明确披露。

固定使用最终 800 步权重，不挑选最好的随机种子；展示页保留 seed17，避免以测试表现挑权重。
报告每个种子的 val/test Mask AP、APsmall、Boundary F1，以及 3 次均值和样本标准差（ddof=1）。
报告配对 E2−E0 差值；仅描述当前数据上的训练随机性，不做显著性宣称，也不把 3 次训练当成 3 个新测试集。
E3 第二轮未改善主指标，本轮不追加其种子，完整保留已有结果。

## 2. 小目标逐例诊断

按原图 GT 面积 `0 < area ≤ 32²` 定义 COCO small；完整图像推理之后才裁剪展示。
边界核对：COCOeval 在 area > 1024 时才排除 small；旧数据审计使用 <1024。
当前 GraspNet 开发/测试没有恰好 1024 像素的实例，两种计数相同；后续数据明确记录边界。
对所有开发和测试 small GT 报告匹配 IoU、Dice、置信度和边界信息，包含漏检。
匹配需考虑图内全部 GT，避免同一预测同时解释多个目标。
这些诊断用于解释既有结果，本轮不据此调参。

## 3. 独立跨数据集检查

若镜像可用，获取官方 BOP T-LESS BOP19 test RGB-D 与可见掩码，下载上限 1 GB，不启用代理。
仅按 GT 面积、场景、物体身份选择小目标较多的有限确认集；选择规则在推理前写入单独协议。
保持原始分辨率、深度单位和可见掩码，不改变 GraspNet 数据或训练。
使用既有 seed17 E0/E2 固定权重，单独报告零样本跨数据集压力测试，不与 GraspNet AP 合并。
若小目标不足，报告实际审计结果，不追加不受限下载。

## 4. 可用性

新增可跨会话存活的本地 Demo 启动、状态检查和停止入口。
状态需核对真实进程及实际服务身份，不能只读取旧 server.json。
加入小目标样本筛选，明确筛选只改变展示，不改变整套评测指标。
通过真实浏览器检查推理、上传、掩码导出、移动端与筛选。

## 保留限制

当前模型输出统一 object 类，未完成 88 物体身份分类。
GraspNet 训练仅两个场景；测试 small 只有一个实例。追加种子不能弥补数据覆盖不足。
跨数据集检查若成功，仍不能证明在课程正式数据上的效果。


## 评测前的格式适配记录

T-LESS 原始 visible masks 在92/100选定帧存在重叠，不能无损压成一张实例ID图。因此在固定选帧后、模型评测前新增可选独立mask格式，保留原PNG及真实面积。COCO仅增加接受该标注格式的入口判断，匹配与编码不变；不对它运行会丢弃重叠GT的单标签图指标。旧104个GraspNet样本张量与指纹完全相同，seed17 E0测试12项COCO指标精确复现。变更记录见 reports/v3/evaluation_source_amendment.json、multi_mask_compatibility.json、evaluation_regression_check.json。
