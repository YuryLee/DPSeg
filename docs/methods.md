# 方法与结构

| 方法 | 核心结构 | 本项目用途 |
|---|---|---|
| Mask R-CNN | ResNet-50、FPN、RPN、RoIAlign、分类/框/掩码头 | 经典RGB基线 |
| Mask2Former | Swin-Tiny、像素解码器、带掩码注意力的查询解码器 | Transformer RGB基线 |
| DA-Fusion课程适配 | 独立RGB/深度Swin-Tiny、四尺度DS/DC融合、Mask2Former解码器 | RGB-D基座 |
| PointRend思路的残差点头 | 不确定点选择、细粒度特征、粗掩码、共享MLP、逐级细化 | 本项目的掩码改进 |

Swin-Tiny是骨干，负责提取特征；Mask2Former是完整分割框架。DA-Fusion关注模态融合，PointRend关注掩码细化，它们可以组合。

## DA-Fusion课程适配

RGB与深度分支各自提取四尺度特征。DS为可变形自注意力，改善各模态特征；DC为双向可变形交叉注意力，交换RGB外观与深度几何信息。融合结果进入Mask2Former像素解码器和查询解码器。

课程版使用双Swin-Tiny，深度按内参反投影为XYZ并附有效性通道。它保留固定版本公开实现的DS/DC和坐标约定，属于课程适配；与论文HHA表达、大骨干和原评测设置的差异见[方法约定](dafusion_method_contract.md)。本项目不将课程AP归作原论文成绩复现。

## 两种点头

基础模型冻结。两个点头共同接收最细融合骨干特征96维、像素解码器特征256维和该实例的粗掩码logit。

深度点头额外接收9维几何信息：中心有效性、四邻域深度差经 `tanh(差值/1mm)` 压缩后的值，以及四组中心/邻居同时有效标记。普通点头本身也使用RGB-D融合特征，因此这组消融比较的是显式局部深度线索。

MLP有3个256维隐藏层，粗掩码logit在各层再次拼入，输出残差logit。输出层零初始化，使初始结果保持基线。训练每实例采784点，75%偏向不确定位置、25%随机；推理从256×256到512再到1024逐级细化。

训练匹配与监督可以使用真值；推理区域来自预测掩码，输入仅RGB、测量深度、有效性和内参。类别、分数、实例数量和顺序固定，细化为空时回退。点头主要改善已发现目标的几何形状，不会产生新的目标查询。

## 概率图深度细化与切片

概率细化对软概率图执行一次由空间距离和深度差加权的邻域平均，再阈值化，保留无效深度与空掩码回退。当前组合采用点头后接这一概率细化步骤。

历史切片系统包含整图与四个640×640角部切片，统一坐标后去重、保留前100个实例，再进行细化。其完整验证、测试和Kaggle记录使用早期第5轮基座与第2轮点头。本轮第15轮基座＋第6轮点头只完成整图评价，尚未对新权重完整评测切片组合。
