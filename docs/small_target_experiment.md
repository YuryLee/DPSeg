# 小目标采样优化实验

2026-10-15，ARS experiment-agent / run；工程机制已检查，正式性能实验进行中。

目标是在现有 DA-Fusion 课程适配上提高 Mask APₛ@[0.50:0.95]。对照是已经完成的原版 DA-Fusion，同为种子 17、五轮课程训练。原版最佳验证 APₛ 为 0.392844，整体 AP 为 0.741043。

本轮保持双 Swin-Tiny、四尺度 DS/DC、800 输入、XYZ+有效性通道、COCO 初始化、优化器及有效批量 8（微批4、累积2）一致。模型仍有 87,517,981 个参数；推理输出、阈值和压缩 RLE 规则一致。

唯一算法变化发生在匹配后的掩码损失采样。原生 Mask2Former 每个匹配实例使用 12,544 点，其中 9,408 点按预测不确定性选择，3,136 点随机选择。对**原始标注面积不超过 1024 像素**的实例，将随机部分的最后 256 点替换为 128 个前景像素中心和 128 个边界带像素中心。总点数和不确定点数量保持不变。

边界带由输入分辨率下的实例标注经 3×3 膨胀减腐蚀得到，包含轮廓两侧。采样允许重复；小实例在缩放后变为空掩码时沿用原生采样，保留其类别与实例；边界带为空时使用前景池。最终层和所有原生辅助损失层都执行此规则。

这会主动改变损失的采样分布，没有做重要性加权修正，不能称为原损失的无偏估计。匈牙利匹配算法保持原样；新增采样会改变后续随机流，因此不宣称两次训练轨迹逐位相同。标注只用于训练损失，推理不使用标注。

已通过八项机制与集成检查，包括普通实例损失、梯度和随机状态的原生等值；小实例点位置与原始面积阈值；单像素和空掩码回退；辅助层梯度；初始化张量完全相同；推理不调用目标损失。真实 GPU 短检查完成24张训练图、3张验证图、3次更新，没有使用测试集。峰值分配显存约23.42 GiB。

正式实验每轮完整训练14,432张，五轮共9,020次更新；每轮完整验证2,584张。按验证 APₛ、AP、较早轮次选权重，最后进行一次2,112张全量测试，并生成 submission.csv、与原版的固定案例对比和验证曲线。

候选采用门槛提前固定为：相对原版最佳验证 APₛ 至少增加0.005，整体 AP 下降不超过0.005。无论是否通过，均保留最终测试结果和下降案例。此门槛是单种子探索的工程选择，不代表统计显著性。当前没有增加边界损失或边界细化头。

五轮正式训练及每轮完整验证均已完成，共9,020次更新、72,160张次，训练图片顺序与原版一致，损失、梯度和学习率记录检查通过。详见[完整训练核对记录](../reports/course_small_target/training_complete_audit.json)。

**验证结论：本次采样规则未通过预设改进门槛，保留原版作为当前推荐模型。** 采样版按 APₛ 选中第四轮，最佳验证 APₛ 为0.303480，整体 AP 为0.718047；原版选中第五轮，分别为0.392844和0.741043。差值为−0.089365和−0.022996。第五轮采样版整体 AP 仍增加，但主指标 APₛ 略降，因此没有用第五轮替换第四轮权重。选定权重的全量测试正在进行。详见[完整验证与权重选择核对](../reports/course_small_target/validation_selection_audit.json)。
