# 补充实验与历史结果

本页保存此前完整实验，供查阅点头类型、训练轮次及早期基线。README 的主消融按五步累计添加组件组织；本页不同训练预算与输入分辨率的结果不能拼成同一条消融。

## 既有补充实验

### 1. 第15轮基座的六组整图消融：实验设置

本轮固定DA-Fusion第15轮基座，仅训练普通点头和深度点头。两种点头各训练6轮，每轮对完整验证集评测六种配置。

| 项目 | 设置 |
|---|---|
| 训练 / 验证图像 | 每轮14,432 / 2,584张，均完整覆盖 |
| 输入 / 输出尺寸 | 1024×1024，整图推理 |
| 可训练部分 | 两个独立点头；DA-Fusion基座全程冻结 |
| 优化器 | AdamW，初始学习率0.0003，权重衰减0.01 |
| 学习率计划 | 100步预热后余弦衰减 |
| 设备与batch | 四卡，每卡2张，全局batch=8 |
| 随机种子 / 更新数 | seed=17；每轮1,804步，共10,824步 |
| 选择规则 | 完整验证APₛ最高，再比较AP，最后选择较早轮次 |

**普通点头也使用RGB-D融合特征。** 两个点头的消融比较的是额外9维显式局部深度线索。以下结果均来自第6轮、同一冻结基座和同一完整验证集。

### 2. 点头与概率图深度细化的作用

| 编号 | 点头类型 | 概率图深度细化 | Mask AP | Mask APₛ |
|---|---|---|---:|---:|
| A1 | 无，DA-Fusion原始输出 | 关闭 | 0.814871 | 0.503742 |
| A2 | 无 | 开启 | 0.851316 | 0.566674 |
| A3 | 普通点头 | 关闭 | 0.813697 | 0.488593 |
| A4 | 普通点头 | 开启 | 0.852257 | 0.561337 |
| A5 | 深度点头 | 关闭 | 0.846843 | 0.547258 |
| **A6** | **深度点头** | **开启** | **0.864680** | **0.586192** |

各组比较得到以下结果：

- **概率图深度细化：** A2相对A1的APₛ增加 **0.062933**。
- **显式局部深度线索：** 在都开启概率细化时，A6相对A4的APₛ增加 **0.024856**；关闭概率细化时，A5相对A3增加 **0.058665**。
- **点头与概率细化的组合：** A6相对A2的APₛ增加 **0.019518**，AP增加 **0.013364**。相对原始输出A1，A6的APₛ总增量为 **0.082451**。

普通点头的A3低于A1，A4的APₛ也低于A2。在当前训练预算下，通用点细化没有带来一致提升；较好的结果来自深度点头与概率细化的组合。以上增量均为0–1标度上的绝对差。

### 4. 早期基线系统对比

三组均从公开COCO权重开始，课程微调5轮，输入短边800。表中为同一2,112张历史本地测试图的结果。

| 方法 | 骨干 / 输入 | 本地测试 Mask AP | 本地测试 Mask APₛ |
|---|---|---:|---:|
| Mask R-CNN | ResNet-50-FPN v2 / RGB | 0.590850 | 0.096327 |
| Mask2Former | Swin-Tiny / RGB | 0.639821 | 0.122838 |
| DA-Fusion课程适配 | 双Swin-Tiny / RGB-D | 0.741837 | 0.256135 |

该表反映基线系统的整体差异，架构、骨干与输入模态共同变化。DS和DC各自的贡献，需要在相同骨干和训练设置下另做移除对照；当前六组点头消融保持这些融合模块不变。

### 5. 历史切片条件下的点头与保护策略对比

以下均固定**第5轮基座、第2轮点头、整图＋四个640切片**，比较追加深度点头及小掩码保护的作用。

| 配置 | 验证AP | 验证APₛ | 本地测试AP | 本地测试APₛ | Kaggle公榜APₛ |
|---|---:|---:|---:|---:|---:|
| 切片＋概率细化 | 0.846840 | 0.611979 | 0.850086 | 0.436858 | 0.47037 |
| 切片＋深度点头＋概率细化 | 0.854941 | 0.622749 | 0.856120 | 0.443073 | 0.47971 |
| 上组＋小掩码保护 | 0.854925 | 0.622857 | 0.856098 | 0.442793 | 未提交 |

在相同切片候选上加入深度点头后，验证APₛ增加 **0.010770**，本地测试APₛ增加 **0.006215**；两次已提交公榜分数的差为 **0.00934**。保护版按规则回退部分掩码，验证APₛ略高，本地测试APₛ略低；历史验证选择了保护版，已提交公榜较高的记录来自未加保护的点头版。

公榜分数为2026-10-17已确认的记录。该表用于比较切片条件下的点头和保护策略；第15轮基座＋第6轮点头尚无对应的完整切片、测试与Kaggle结果。
