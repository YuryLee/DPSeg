# 课程评价指标与提交格式

主指标为 **Mask APₛ@[0.50:0.95]**，范围0–1，越高越好。它同时衡量小目标能否被发现、掩码是否准确，以及置信度排序是否合理。

## 如何计算

1. 预测与真值计算掩码 IoU，即交集面积除以并集面积。
2. 在 IoU=0.50、0.55、…、0.95 十个阈值分别评价，按置信度排序进行 COCO 匹配和精确率—召回率计算。
3. 对各阈值的 AP 平均。课程只有一个前景类别 `component`。
4. APₛ 使用原标注面积的 COCO small 范围 `[0,1024]`；模型内部缩放不改变这个分组。

整体 Mask AP 包含全部目标尺寸。APₛ只描述小目标，两者不能互换。COCO 的面积忽略、crowd 和每图上限规则保留在原评价代码中；不能把数据预先筛成小掩码后另算精确率来替代它，也不能逐图计算 AP 后简单平均。

本项目复用 `pycocotools.COCOeval(iouType='segm')`，使用原始标注面积、10个IoU阈值、101个召回采样点和 `maxDets=[1,10,100]`。入口为 `rgbd_seg/course_finetune_eval.py`，RGB-D包装为 `rgbd_seg/course_dafusion_eval.py`。

## 不同来源的分数

| 来源 | 数据范围 | 用途 |
|---|---|---|
| 完整验证 | 2,584张有标注图 | 选择模型、轮次和配置 |
| 本地历史测试 | 下载归档中的2,112张测试图及本地标注 | 已完成实验的独立列报 |
| Kaggle公榜 | 官方约30%的测试数据 | 官方提交记录 |
| Kaggle最终榜 | 官方其余约70%的测试数据 | 官方最终评分 |

本轮 `0.586192` 是完整整图验证 APₛ，不能与历史 Kaggle 公榜 `0.47971` 当作同一集合直接计算提升。历史测试和公榜已被多次查看，本轮新增六轮只使用 train/val 选择；不能宣称整个项目从未接触测试成绩。

## CSV要求

提交文件两列：`image_id`、`PredictionString`。每行对应一张官方测试图，`PredictionString` 是 JSON 列表。每个实例包含：

- `category_id`：课程单类使用1。
- `score`：0–1置信度。
- `segmentation.size`：`[1024,1024]`。
- `segmentation.counts`：COCO压缩RLE的字符串。

每图最多100个实例，无预测时填 `[]`。JSON中的双引号需要按CSV规则转义；应使用项目现有写入和校验代码，避免手工拼接。RLE使用COCO的列优先顺序，不是将掩码按普通行顺序展开。

提交校验实现位于 `rgbd_seg/course_submission.py`。历史 CSV、逐图预测和完整解码校验记录保留在本机各实验目录；本轮新增六轮尚未导出测试 CSV 或提交 Kaggle。
