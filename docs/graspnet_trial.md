# GraspNet 真实数据试验记录

用户明确要求使用 GraspNet 子集，并要求经镜像下载、不开启代理。本轮沿用 ARS 实验流程，先检查数据，再按预先确定的预算训练与验证。

## 数据来源与许可

- 原始数据及标签归 GraspNet / MVIG / 上海交通大学团队所有。[官方格式与许可说明](https://graspnet.net/datasets.html)允许非商业使用并注明 BY-NC-SA；课程试验保留来源与归属，不将镜像的许可字段当成放宽原始许可。
- 使用公开镜像 hf-mirror.com 的 `DravenALG/GraspNet-1Billion`，固定 revision `1f9db26044cd2a7e629bbb465be3665364cbf2bf`。这是第三方转载，不是官方镜像认证。
- 通过镜像提供的 Xet 下载协议读取原始 scenes.tar 的选定区间，保留 TLS 校验，不启用代理。完整归档约142.5GB，未整体下载。完整归档 SHA256 未重新计算；已校验 tar 头、PNG 格式，并记录每个取得文件的 SHA256。
- 下载记录：`reports/graspnet_labels_download.json`。下载工具不持久化公开访问令牌或带签名的临时地址。
- 初次尝试的 `Litian2002/graspnet1b-rsi-exam` 925MB 包没有像素实例标签，因此未把其抓取标注当成分割真值，也未用于本轮监督训练。

## 预先确定的试验规则

- 从镜像归档顺序中取得最先遇到的3个官方训练场景（scene0–99）；每个使用帧0、64、128、192。
- 训练与验证按场景互斥。选择划分时仅查看类别覆盖与目标面积，不查看模型表现。验证集是开发验证，不是官方测试集。
- 默认类别为88个 GraspNet 物体身份，保留原始标注ID；它们不是88种语义物体类别。未在训练场景出现的验证身份必须记录。
- 数据保留1280×720原始分辨率；模型内部统一缩放。AP小目标面积依据原图实例掩码，不能按缩小后的图像重新划分。
- E0/E2/E3使用同一Tiny-FPN、随机种子17、初始RGB权重、训练抽样、AdamW学习率0.002、batch2、600步，最终步权重直接评估。CPU2线程，无GPU分配时不占用共享GPU。
- 只做一次固定预算探索，不按验证分数挑选权重。短小子集、单随机种子、随机初始化均限制结论。

## 类别覆盖规则补充（训练前）

取得scene17与20后发现两者可见身份完全不相交。如果三场景的最佳划分仍有超过一半验证身份未出现在训练中，则主试验使用统一的 `object` 类，保留各原始物体的独立掩码，先检验类别无关实例分割。此时不宣称已完成88身份分类，demo和报告必须说明；88身份映射仍由转换器支持，待扩充覆盖匹配的训练场景再验证。这个决定依据标签覆盖，在任何本轮600步模型训练和验证之前作出。

结果将在实际训练和官方COCO评测后填写。

## 已确定的划分（训练前）

已取得scene2、17、20各4帧，共12帧、111个可见实例、5个small。身份模式最佳覆盖仅4/9=44.4%，触发预先设定的类别无关规则。统一为object后，三种划分的类别覆盖均100%，按小目标数量选择验证scene17（4个small、41个实例），训练scene2+20（8帧、70个实例，其中1个small）。该划分完全依据标签完成，没有使用模型分数。
